MCP-Discord authenticates with Discord using a bot token and acts on behalf of a bot you own. Before you can connect your AI tool to Discord, you need to create a bot application, enable the correct privileged intents, generate an invite URL with the right permissions, and add the bot to your server.

<Warning>
  Your bot token is a secret credential that grants full control over your bot. Never share it, commit it to version control, or expose it in client-side code. If a token is compromised, regenerate it immediately in the Discord Developer Portal.
</Warning>

## Setup steps

<Steps>
  <Step title="Create a new application">
    Open the [Discord Developer Portal](https://discord.com/developers/applications) and click **New Application**. Give it a name (this becomes your bot's display name by default), accept the terms, and click **Create**.
  </Step>

  <Step title="Add a bot and copy the token">
    In the left sidebar, select the **Bot** tab. Click **Add Bot** and confirm. Under the **Token** section, click **Reset Token** to reveal your token, then copy and store it somewhere safe — you will use it as the `DISCORD_TOKEN` value when configuring MCP-Discord.

    <Note>
      Discord only shows the full token once after generation. If you navigate away without saving it, you will need to reset it to get a new one.
    </Note>
  </Step>

  <Step title="Enable Privileged Gateway Intents">
    Still on the **Bot** tab, scroll down to the **Privileged Gateway Intents** section and enable all three intents:

    - **Presence Intent** — allows the bot to receive presence updates.
    - **Server Members Intent** — required for member management tools.
    - **Message Content Intent** — required for reading the content of messages.

    Click **Save Changes** after enabling them.
  </Step>

  <Step title="Generate an invite URL with the required permissions">
    In the left sidebar, go to **OAuth2 → URL Generator**. Under **Scopes**, select **bot**. Under **Bot Permissions**, select the following:

    | Permission | Required for |
    |---|---|
    | View Channel | Reading channels and messages |
    | Send Messages | Posting messages |
    | Send Messages in Threads | Posting inside threads |
    | Create Public Threads | Opening new threads |
    | Manage Messages | Editing and deleting messages |
    | Manage Threads | Archiving and deleting threads |
    | Manage Channels | Creating and editing channels |
    | Manage Webhooks | Creating and managing webhooks |
    | Manage Roles | Assigning and removing roles |
    | Add Reactions | Reacting to messages |

    <Note>
      For quick local testing on a private server you control, you can select **Administrator** instead of individual permissions. Do not use Administrator in production or on shared servers — always apply the minimum permissions your workflow actually requires.
    </Note>

    Copy the generated URL at the bottom of the page.
  </Step>

  <Step title="Invite the bot to your server">
    Paste the generated URL into your browser. Select the server you want to add the bot to, review the requested permissions, and click **Authorise**. You must have the **Manage Server** permission on the target server.

    Repeat this step for every server you want MCP-Discord to be able to manage.
  </Step>
</Steps>

## Finding Discord IDs

Discord IDs (guild ID, channel ID, user ID) are called **snowflakes** — 64-bit integers represented as strings. Many MCP-Discord tools require you to pass these IDs as arguments.

<Tip>
  Enable **Developer Mode** in Discord to copy IDs directly from the UI. Go to **User Settings → Advanced → Developer Mode** and toggle it on. You can then right-click any server, channel, message, or user and select **Copy ID**.
</Tip>
