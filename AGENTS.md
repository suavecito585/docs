# The 40 Thieves docs hub

- Mintlify site. Site settings are in `docs.base.json`; `docs.json` is generated by the sync
  workflow and overwritten on every run, so never edit it by hand.
- Project folders (such as `reliquary-tc/`) are synced from each project's repository and
  overwritten on every run. Edit those docs in the project's own repository.
- Hand-written pages here: `index.mdx` only.
- Preview with `mint dev`; check with `mint validate` and `mint broken-links`.
