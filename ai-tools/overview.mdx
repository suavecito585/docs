The Model Context Protocol (MCP) is an open standard that lets AI assistants call external services — like Discord — directly from their chat interface. MCP-Discord implements this protocol as a server, so tools such as Claude Desktop, Cursor, and Windsurf can send messages, manage channels, and perform server operations without any custom integration code on your part.

## How it works

When you configure an MCP-compatible AI tool to use MCP-Discord, the tool launches the server as a local subprocess over **stdio transport**. Your AI assistant discovers the available Discord tools automatically and can invoke them whenever you ask it to interact with Discord. The server authenticates with Discord using your bot token and executes the requested actions on your behalf.

No separate process to manage, no open ports required — the AI tool starts and stops MCP-Discord automatically alongside your session.

## Before you begin

Every guide in this section assumes your Discord bot is already created and has the necessary permissions granted in your server. If you haven't done that yet, complete the [bot setup](/concepts/bot-setup) first, then return here to connect your chosen AI tool.

<Note>
  MCP-Discord requires Node.js v18 or later. All guides in this section include a step to verify your Node.js version before proceeding.
</Note>
