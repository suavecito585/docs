MCP-Discord is a [Model Context Protocol (MCP)](https://modelcontextprotocol.io) server that bridges your AI assistant directly to Discord. Whether you're automating community management, building bots through conversation, or integrating Discord into your AI workflows, MCP-Discord gives Claude, Cursor, Windsurf, and any other MCP-compatible client full programmatic access to your Discord servers — no custom bot code required.

## How it works

MCP-Discord runs as a local or remote process alongside your AI assistant. It listens for MCP tool calls, translates them into Discord API requests using your bot token, and returns structured results back to the model. You choose between two transport modes:

- **stdio** — the default mode, ideal for local AI tools like Claude Desktop and Cursor that launch MCP servers as subprocesses.
- **HTTP (Streamable)** — exposes an `/mcp` endpoint for remote or server-based deployments, accessible over the network.

<Note>
  MCP-Discord requires a Discord bot token and Node.js v18 or later. See the [Quickstart](/quickstart) to get set up in a few minutes.
</Note>
