The messaging tools let your AI assistant interact with Discord text channels directly — posting messages on your behalf, fetching channel history, running advanced searches across a server, and cleaning up messages when needed. All you need is the channel or server ID; your AI handles the rest.

<Note>
  You'll need Discord snowflake IDs for channels, servers, messages, and users. Enable **Developer Mode** in Discord (User Settings → Advanced → Developer Mode), then right-click any item to copy its ID.
</Note>

---

## discord_send

Sends a message to a text channel. You can optionally reply to an existing message by providing its ID, which creates a threaded reply visible to everyone in the channel.

**Example prompt:** *"Send 'Deployment complete ✅' to the #deployments channel."*

<ParamField body="channelId" type="string" required>
  The ID of the Discord text channel to send the message to.
</ParamField>

<ParamField body="message" type="string" required>
  The text content of the message to send.
</ParamField>

<Accordion title="Optional parameters">
  <ParamField body="replyToMessageId" type="string">
    The ID of the message to reply to. When set, Discord displays the message as a threaded reply beneath the original.
  </ParamField>
</Accordion>

```text Example prompts
"Post 'Stand-up in 5 minutes' to channel 123456789012345678."
"Reply to message 987654321098765432 in #general saying 'Thanks for the update!'"
```

## discord_read_messages

Reads messages from a text channel. By default it fetches the 50 most recent messages. Use the filtering parameters to target a specific point in time or a range of messages by snowflake ID or ISO 8601 timestamp.

**Example prompt:** *"Show me the last 20 messages from #announcements."*

<ParamField body="channelId" type="string" required>
  The ID of the channel to read messages from.
</ParamField>

<Accordion title="Optional parameters">
  <ParamField body="limit" type="number">
    Number of messages to return. Accepts values from `1` to `100`. Defaults to `50`.
  </ParamField>

  <ParamField body="before" type="string">
    Return only messages sent **before** this point. Accepts a message snowflake ID or an ISO 8601 timestamp (e.g. `2024-06-01T12:00:00Z`).
  </ParamField>

  <ParamField body="after" type="string">
    Return only messages sent **after** this point. Accepts a message snowflake ID or an ISO 8601 timestamp.
  </ParamField>

  <ParamField body="around" type="string">
    Return messages centered **around** this point. Accepts a message snowflake ID or an ISO 8601 timestamp.
  </ParamField>
</Accordion>

<Warning>
  You can only specify one of `before`, `after`, or `around` in a single request. Providing more than one will result in an error.
</Warning>

```text Example prompts
"Read the last 100 messages from channel 123456789012345678."
"Show messages in #general sent after 2024-11-01T00:00:00Z."
"Get messages around message ID 987654321098765432 in #dev-chat."
```

## discord_search_messages

Searches messages across an entire server with powerful filters. You can narrow results by content keyword, author, attachment type, pinned status, whether the author is a bot or webhook, and more. Results are paginated using `limit` and `offset`.

**Example prompt:** *"Search #dev-chat for messages containing 'error' sent by bots in the last week."*

<ParamField body="guildId" type="string" required>
  The ID of the Discord server (guild) to search within.
</ParamField>

<Accordion title="Optional parameters">
  <ParamField body="content" type="string">
    Keyword or phrase to search for in message content.
  </ParamField>

  <ParamField body="authorId" type="string">
    Filter results to messages sent by this user ID.
  </ParamField>

  <ParamField body="mentions" type="string">
    Filter results to messages that mention this user ID.
  </ParamField>

  <ParamField body="has" type="string">
    Filter by attachment or embed type. Accepted values: `link`, `embed`, `file`, `poll`, `image`, `video`, `sound`, `sticker`, `snapshot`.
  </ParamField>

  <ParamField body="channelId" type="string">
    Restrict the search to a specific channel within the server.
  </ParamField>

  <ParamField body="pinned" type="boolean">
    When `true`, returns only pinned messages. When `false`, excludes pinned messages.
  </ParamField>

  <ParamField body="authorType" type="string">
    Filter by the type of author. Accepted values: `user`, `bot`, `webhook`.
  </ParamField>

  <ParamField body="minId" type="string">
    Return only messages with a snowflake ID greater than this value (i.e., sent after this message).
  </ParamField>

  <ParamField body="maxId" type="string">
    Return only messages with a snowflake ID less than this value (i.e., sent before this message).
  </ParamField>

  <ParamField body="sortBy" type="string">
    How to sort results. Accepted values: `timestamp` (default), `relevance`.
  </ParamField>

  <ParamField body="sortOrder" type="string">
    Sort direction. Accepted values: `desc` (newest first, default), `asc` (oldest first).
  </ParamField>

  <ParamField body="limit" type="number">
    Number of results to return. Accepts values from `1` to `100`. Defaults to `25`.
  </ParamField>

  <ParamField body="offset" type="number">
    Number of results to skip for pagination. Defaults to `0`.
  </ParamField>
</Accordion>

```text Example prompts
"Search server 123456789012345678 for messages containing 'outage'."
"Find all messages with images sent by bots in #media."
"Search for pinned messages in server 123456789012345678 sorted by relevance."
```

## discord_edit_message

Edits the content of a message that the bot previously sent. You cannot use this tool to edit messages written by other users or bots.

**Example prompt:** *"Update the message I just sent in #status to say 'All systems operational.'"*

<ParamField body="channelId" type="string" required>
  The ID of the channel containing the message.
</ParamField>

<ParamField body="messageId" type="string" required>
  The ID of the message to edit.
</ParamField>

<ParamField body="content" type="string" required>
  The new text content that will replace the existing message body.
</ParamField>

<Warning>
  You can only edit messages that the bot itself sent. Attempting to edit a message from another user will return a permission error.
</Warning>

```text Example prompts
"Edit message 987654321098765432 in channel 123456789012345678 to say 'Meeting rescheduled to 3pm'."
```

## discord_delete_message

Deletes a message from a channel. You can provide an optional reason, which appears in the server's audit log.

**Example prompt:** *"Delete the duplicate announcement in #general."*

<ParamField body="channelId" type="string" required>
  The ID of the channel containing the message.
</ParamField>

<ParamField body="messageId" type="string" required>
  The ID of the message to delete.
</ParamField>

<Accordion title="Optional parameters">
  <ParamField body="reason" type="string">
    A short explanation for the deletion. This text is recorded in the server's audit log and is visible to server moderators.
  </ParamField>
</Accordion>

```text Example prompts
"Delete message 987654321098765432 from channel 123456789012345678."
"Remove that message with reason 'Posted in wrong channel'."
```

## Server and authentication tools

These tools handle bot authentication and server discovery. You rarely need to call them explicitly — `discord_login` runs automatically when MCP-Discord starts.

### discord_login

Authenticates the bot with Discord using the configured bot token. This tool is called automatically at startup and typically does not need to be invoked manually.

### discord_list_servers

Returns a list of every Discord server the bot is currently a member of, including each server's ID and name. Use this to look up a `guildId` when you don't have it on hand.

**Example prompt:** *"Which servers is the bot in?"*

### discord_get_server_info

Fetches detailed information about a specific server, including its name, icon, member count, and channel list.

**Example prompt:** *"Show me details about server 123456789012345678."*

<ParamField body="guildId" type="string" required>
  The ID of the Discord server to retrieve information for.
</ParamField>
