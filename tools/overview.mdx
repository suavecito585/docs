MCP-Discord gives your AI assistant direct access to Discord through 43 callable tools. When you type a request in natural language — "send a message to #general" or "search for messages mentioning deployments" — your AI translates that intent into a tool call and executes it against Discord's API on your behalf. No manual API work required.

## How tools work

Each tool has a name, a set of required parameters, and optional parameters that refine its behavior. Your AI resolves parameter values from context (a channel name you mention, a server you're already discussing) or asks you to clarify when it needs more information. You interact naturally; the tool calls happen in the background.

<Note>
  Most tools require Discord **snowflake IDs** for channels, servers, messages, and users. Enable **Developer Mode** in your Discord settings (User Settings → Advanced → Developer Mode), then right-click any server, channel, or message to copy its ID.
</Note>

## Tools by category

### Messaging

Tools for sending, reading, searching, editing, and deleting messages in text channels, plus authentication and server discovery.

| Tool | Description |
|---|---|
| `discord_send` | Send a message to a channel, with optional reply threading |
| `discord_read_messages` | Read channel history with optional date and snowflake filters |
| `discord_search_messages` | Search a server's messages with advanced filters (author, content, attachments, and more) |
| `discord_edit_message` | Edit a message previously sent by the bot |
| `discord_delete_message` | Delete a message from a channel |
| `discord_login` | Authenticate the bot with Discord (called automatically on startup) |
| `discord_list_servers` | List all servers the bot belongs to |
| `discord_get_server_info` | Retrieve detailed information about a specific server |

### Reactions

Tools for managing emoji reactions on messages.

| Tool | Description |
|---|---|
| `discord_add_reaction` | Add a single emoji reaction to a message |
| `discord_add_multiple_reactions` | Add several emoji reactions to a message in one call |
| `discord_remove_reaction` | Remove a reaction from a message (bot's own or a specific user's) |
| `discord_get_reaction_users` | List all users who reacted with a specific emoji |

### Webhooks

Tools for creating and managing Discord webhooks.

| Tool | Description |
|---|---|
| `discord_create_webhook` | Create a new webhook for a channel |
| `discord_send_webhook_message` | Post a message through a webhook with a custom username and avatar |
| `discord_edit_webhook` | Update a webhook's name, avatar, or target channel |
| `discord_delete_webhook` | Delete a webhook permanently |

### Channels

Tools for creating and managing text, voice, and category channels.

| Tool | Description |
|---|---|
| `discord_create_text_channel` | Create a new text channel in a server |
| `discord_create_forum_channel` | Create a new forum channel |
| `discord_create_voice_channel` | Create a new voice channel |
| `discord_edit_channel` | Edit a channel's name, topic, or other settings |
| `discord_delete_channel` | Delete a channel from a server |
| `discord_create_category` | Create a new channel category |
| `discord_edit_category` | Edit an existing category |
| `discord_delete_category` | Delete a category |
| `discord_set_channel_permissions` | Set permission overwrites for a role or user in a channel |
| `discord_remove_channel_permissions` | Remove permission overwrites from a channel |

### Forums

Tools for managing forum channels and threads.

| Tool | Description |
|---|---|
| `discord_get_forum_channels` | List all forum channels in a server |
| `discord_create_forum_post` | Create a new post (thread) in a forum channel |
| `discord_get_forum_post` | Retrieve a specific forum post |
| `discord_list_forum_threads` | List threads in a forum channel |
| `discord_reply_to_forum` | Post a reply inside a forum thread |
| `discord_update_forum_post` | Edit the title, tags, or status of a forum post |
| `discord_delete_forum_post` | Delete a forum post |
| `discord_get_forum_tags` | Retrieve available tags for a forum channel |
| `discord_set_forum_tags` | Define the complete set of tags for a forum channel |

### Roles

Tools for managing server roles and role assignments.

| Tool | Description |
|---|---|
| `discord_list_roles` | List all roles in a server |
| `discord_create_role` | Create a new role with a name, color, and permissions |
| `discord_edit_role` | Edit an existing role's properties |
| `discord_delete_role` | Delete a role from a server |
| `discord_assign_role` | Assign a role to a server member |
| `discord_remove_role` | Remove a role from a server member |

### Members

Tools for inspecting server membership.

| Tool | Description |
|---|---|
| `discord_list_members` | List members in a server with pagination support |
| `discord_get_member` | Retrieve details about a specific server member |
