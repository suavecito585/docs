MCP-Discord gives you full control over your server's channel structure. Use these tools to create and edit text, forum, and voice channels, group them under categories, and define granular permission overrides for specific roles or users — all through your AI assistant.

<Note>
  The optional `reason` parameter is available on most tools in this reference. Whatever string you provide appears in your server's **Discord Audit Log**, making it easy to track why a change was made.
</Note>

<Tip>
  Pass a `categoryId` when creating or editing a channel to place it under an existing category. You can copy a category's ID the same way you copy a channel ID: right-click the category name in Discord with Developer Mode enabled.
</Tip>

---

## Text Channels

### `discord_create_text_channel`

Creates a new text channel in a server. You can optionally set a topic and nest it inside a category at creation time.

<ParamField body="guildId" type="string" required>
  The ID of your Discord server. Right-click the server name in Discord (with Developer Mode enabled) to copy the ID.
</ParamField>

<ParamField body="channelName" type="string" required>
  The name for the new text channel. Discord will slugify this automatically (spaces become hyphens, uppercase is lowercased).
</ParamField>

<Accordion title="Optional parameters">
  <ParamField body="topic" type="string">
    A short description shown at the top of the channel and in channel lists. Helps members understand the channel's purpose.
  </ParamField>

  <ParamField body="categoryId" type="string">
    The ID of the category to nest this channel under. If omitted, the channel is created at the top level of the server.
  </ParamField>
</Accordion>

**Example prompt:** *"Create a text channel called `release-notes` in my server with the topic 'Official release announcements', under the Announcements category."*

---

### `discord_edit_channel`

Updates an existing channel's settings. All fields are optional — you only need to supply the values you want to change.

<ParamField body="channelId" type="string" required>
  The ID of the channel to edit. Right-click the channel name in Discord (with Developer Mode enabled) to copy it.
</ParamField>

<Accordion title="Optional parameters">
  <ParamField body="name" type="string">
    A new name for the channel.
  </ParamField>

  <ParamField body="topic" type="string">
    A new topic string to display at the top of the channel.
  </ParamField>

  <ParamField body="parentId" type="string">
    The ID of a category to move the channel into, or `null` to remove it from its current category.
  </ParamField>

  <ParamField body="position" type="number">
    The channel's position in the sidebar list. Lower numbers appear higher in the list.
  </ParamField>

  <ParamField body="reason" type="string">
    A reason recorded in the server's Audit Log.
  </ParamField>
</Accordion>

**Example prompt:** *"Rename channel `1234567890` to `announcements` and move it into the General category."*

---

### `discord_delete_channel`

Permanently deletes a channel and all of its message history.

<Warning>
  Deleting a channel is irreversible. All messages, pins, and webhooks in the channel are permanently removed. Make sure you have the right channel ID before proceeding.
</Warning>

<ParamField body="channelId" type="string" required>
  The ID of the channel to delete.
</ParamField>

<Accordion title="Optional parameters">
  <ParamField body="reason" type="string">
    A reason recorded in the server's Audit Log.
  </ParamField>
</Accordion>

**Example prompt:** *"Delete the channel with ID `1234567890` — it's no longer needed."*

## Forum Channels

### `discord_create_forum_channel`

Creates a new forum-type channel in a server. Forum channels are different from text channels — each post in a forum becomes its own thread. See the [Forums reference](/tools/forums) for tools that manage posts and tags inside a forum channel.

<ParamField body="guildId" type="string" required>
  The ID of your Discord server.
</ParamField>

<ParamField body="name" type="string" required>
  The name for the new forum channel.
</ParamField>

<Accordion title="Optional parameters">
  <ParamField body="topic" type="string">
    Guidelines or a description for the forum, displayed to members before they post.
  </ParamField>

  <ParamField body="categoryId" type="string">
    The ID of the category to place this forum channel under.
  </ParamField>

  <ParamField body="reason" type="string">
    A reason recorded in the server's Audit Log.
  </ParamField>
</Accordion>

**Example prompt:** *"Create a forum channel called `bug-reports` in my server with the guidelines 'Please include steps to reproduce', under the Support category."*

---

## Voice Channels

### `discord_create_voice_channel`

Creates a new voice channel in a server. You can optionally cap how many users can join simultaneously.

<ParamField body="guildId" type="string" required>
  The ID of your Discord server.
</ParamField>

<ParamField body="channelName" type="string" required>
  The name for the new voice channel.
</ParamField>

<Accordion title="Optional parameters">
  <ParamField body="categoryId" type="string">
    The ID of the category to nest this voice channel under.
  </ParamField>

  <ParamField body="userLimit" type="number">
    Maximum number of users allowed in the channel at once. Accepts `0` through `99`. Set to `0` for unlimited. Defaults to unlimited if omitted.
  </ParamField>

  <ParamField body="reason" type="string">
    A reason recorded in the server's Audit Log.
  </ParamField>
</Accordion>

**Example prompt:** *"Create a voice channel called `Team Standup` with a user limit of 10, under the Meetings category."*

## Categories

Categories are container groups that let you visually organize channels in the sidebar.

### `discord_create_category`

Creates a new category in a server.

<ParamField body="guildId" type="string" required>
  The ID of your Discord server.
</ParamField>

<ParamField body="name" type="string" required>
  The name for the new category.
</ParamField>

<Accordion title="Optional parameters">
  <ParamField body="position" type="number">
    Where in the sidebar the category appears. Lower numbers appear higher.
  </ParamField>

  <ParamField body="reason" type="string">
    A reason recorded in the server's Audit Log.
  </ParamField>
</Accordion>

**Example prompt:** *"Create a new category called `Community` at position 2 in my server."*

---

### `discord_edit_category`

Updates an existing category's name or position.

<ParamField body="categoryId" type="string" required>
  The ID of the category to edit.
</ParamField>

<Accordion title="Optional parameters">
  <ParamField body="name" type="string">
    A new name for the category.
  </ParamField>

  <ParamField body="position" type="number">
    The new sidebar position for the category.
  </ParamField>

  <ParamField body="reason" type="string">
    A reason recorded in the server's Audit Log.
  </ParamField>
</Accordion>

**Example prompt:** *"Rename the category `9876543210` to `Community Hub` and move it to position 1."*

---

### `discord_delete_category`

Permanently deletes a category. Channels nested inside the category are **not** deleted — they become uncategorized.

<ParamField body="categoryId" type="string" required>
  The ID of the category to delete.
</ParamField>

<Accordion title="Optional parameters">
  <ParamField body="reason" type="string">
    A reason recorded in the server's Audit Log.
  </ParamField>
</Accordion>

**Example prompt:** *"Delete the `Archive` category. Leave the channels inside it intact."*

## Channel Permissions

Permission overrides let you grant or deny specific permissions to a role or individual user on a single channel or category, supplementing (or overriding) your server's default role permissions.

### `discord_set_channel_permissions`

Sets permission overrides for a role or user on a channel or category. Pass permission flag strings in `allow` or `deny` to explicitly grant or deny each permission. Any permission not listed retains its inherited value.

<ParamField body="channelId" type="string" required>
  The ID of the channel or category to configure permissions on.
</ParamField>

<ParamField body="roleId" type="string" required>
  The ID of the role **or** user to set overrides for. When targeting a specific user, provide their user ID.
</ParamField>

<Accordion title="Optional parameters">
  <ParamField body="allow" type="string[]">
    An array of permission flag strings to explicitly **grant**. Example: `['ViewChannel', 'SendMessages', 'AddReactions']`.
  </ParamField>

  <ParamField body="deny" type="string[]">
    An array of permission flag strings to explicitly **deny**. Example: `['SendMessages', 'CreatePublicThreads']`.
  </ParamField>

  <ParamField body="reason" type="string">
    A reason recorded in the server's Audit Log.
  </ParamField>
</Accordion>

<Tip>
  Common permission flag names for `allow` and `deny` arrays: `ViewChannel`, `SendMessages`, `ManageMessages`, `ManageChannels`, `ManageWebhooks`, `ManageRoles`, `AddReactions`, `CreatePublicThreads`, `CreatePrivateThreads`, `ManageThreads`, `AttachFiles`, `EmbedLinks`, `MentionEveryone`. See the [Discord developer documentation](https://discord.com/developers/docs/topics/permissions) for the complete list.
</Tip>

**Example prompt:** *"On channel `1234567890`, deny `SendMessages` and `AddReactions` for the `Muted` role, and allow `ViewChannel`."*

---

### `discord_remove_channel_permissions`

Removes all permission overrides for a role or user on a channel, reverting them to the server's inherited defaults.

<ParamField body="channelId" type="string" required>
  The ID of the channel to remove overrides from.
</ParamField>

<ParamField body="roleId" type="string" required>
  The ID of the role or user whose overrides should be removed.
</ParamField>

<Accordion title="Optional parameters">
  <ParamField body="reason" type="string">
    A reason recorded in the server's Audit Log.
  </ParamField>
</Accordion>

**Example prompt:** *"Remove all permission overrides for the `Moderator` role on channel `1234567890`."*
