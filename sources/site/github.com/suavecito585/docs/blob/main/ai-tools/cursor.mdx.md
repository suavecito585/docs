Set up Cursor to help you write and maintain your Mintlify documentation.

## Prerequisites

- Cursor editor installed

## Setup

Open the root of your documentation repository where \`docs.json\` is located. In the integrated terminal, run:

```shell
npx skills add https://mintlify.com/docs
```

This gives Cursor Mintlify's component reference, writing standards, and workflow guidance.

Edit \`AGENTS.md\` in your project root to add project-specific terminology, style preferences, and content boundaries. Open a file and use Cursor's AI features to draft and edit documentation.
