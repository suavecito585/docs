Set up Windsurf's Cascade AI assistant to help you write and maintain your Mintlify documentation.

## Prerequisites

- Windsurf editor installed

## Setup

Open the root of your documentation repository where \`docs.json\` is located. In the integrated terminal, run:

```shell
npx skills add https://mintlify.com/docs
```

This gives Windsurf Mintlify's component reference, writing standards, and workflow guidance.

Edit \`AGENTS.md\` in your project root to add project-specific terminology, style preferences, and content boundaries. Open a file and use Cascade to draft and edit documentation.
